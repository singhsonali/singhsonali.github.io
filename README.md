# Sonali Singh - Personal Portfolio

Personal portfolio website hosted on GitHub Pages.

🌐 **Live Site:** [singhsonali.github.io](https://singhsonali.github.io)

## About

Clean, responsive single-page portfolio showcasing my professional experience in enterprise SaaS, cloud security, and observability platforms.

## Features

- 📱 **Responsive Design** - Optimized for desktop, tablet, and mobile
- 🏢 **Interactive Timeline** - Professional experience with company logos
- 🎓 **Education Section** - Georgia Tech credentials
- 📧 **Privacy-Preserving Contact** - Form powered by Formspree
- ✨ **Modern UI** - Smooth animations and hover effects

## Tech Stack

- **Template:** [Strata by HTML5 UP](https://html5up.net/strata)
- **Hosting:** GitHub Pages
- **Contact Form:** Formspree
- **Design:** Pure HTML/CSS/JS (no build process)
