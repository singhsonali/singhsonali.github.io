# Claude Code Instructions for GitHub Pages Project

## Project Context
This is a simple static HTML personal website using the Strata template from HTML5 UP, hosted on GitHub Pages.

## Command Execution Policy
- For git operations, execute directly but explain what's happening
- For GitHub CLI commands, execute directly
- No build process needed - it's plain HTML/CSS/JS

## Development Guidelines
- Simple HTML/CSS/JS - no frameworks or build tools
- Keep design clean and professional
- Maintain responsive design for mobile
- Company logos stored in `images/logos/`
- All styling in `<style>` tag or `assets/css/main.css`

## File Structure
- `index.html` - Single-page website with all sections
- `assets/css/` - Stylesheets
- `assets/js/` - JavaScript files
- `images/logos/` - Company and school logos
- `images/` - Other images and assets
- `Sonali Singh Resume.md` - PRIVATE (in .gitignore, never commit)

## Privacy & Security
- Resume file is gitignored and stays local only
- Contact form uses Formspree (https://formspree.io/f/xjkjlkwa) to protect email
- No personal info (phone, address) exposed on site
