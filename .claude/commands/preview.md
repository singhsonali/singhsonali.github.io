To preview your website locally:

**Option 1 - Direct open (quick preview):**
```bash
open /Users/sonali/Dev/singhsonali.github.io/index.html
```

**Option 2 - Local server (better for testing):**
```bash
cd /Users/sonali/Dev/singhsonali.github.io
python3 -m http.server 8000
```
Then open http://localhost:8000 in your browser.

Press Ctrl+C to stop the server.
